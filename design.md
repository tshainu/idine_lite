# iDine Lite — Design System

## Brand
- App Name: iDine Lite
- Tagline: Restaurant Specialist

## Colors
```
Primary Blue:    #1A73C8
Primary Dark:    #1558A0
Green/Confirm:   #2E7D32
Red/Cancel:      #C62828
Orange/Warn:     #E65100
Background:      #F0F2F5
Card:            #FFFFFF
Surface:         #FAFAFA
Border:          #E0E0E0
Text Primary:    #212121
Text Secondary:  #757575
Text Muted:      #9E9E9E
White:           #FFFFFF
```

## Typography
- Font: Poppins (via expo-google-fonts or system fallback)
- Heading: Poppins SemiBold 20–24px
- Subheading: Poppins Medium 16px
- Body: Poppins Regular 14px
- Caption: Poppins Regular 12px
- Button: Poppins SemiBold 15px

## Spacing
- Base unit: 8px
- Padding: 16px standard, 12px compact, 24px spacious
- Border radius: 8px cards, 6px buttons, 4px inputs

## Components
- Header: Blue #1A73C8, white title + icons
- Buttons: Primary blue, rounded 6px, white text
- Confirm buttons: Green #2E7D32
- Destructive buttons: Red #C62828
- Cards: White bg, 8px radius, light shadow
- Category tabs: Scrollable, selected = blue bg + white text
- Item cards: White, food image top, name + price + Select button
- Bottom action bar: White, icon + label tiles

## Layout
- Status bar: Blue (same as header)
- Tab/Bottom nav: White bg, blue active icon
- Modal overlays: Dark translucent backdrop, white card centered

## Screens
1. Splash — dark blue (#1A73C8) full screen, white iDine logo centered
2. Login — white card on light bg, mascot illustration, 3 fields
3. Dashboard — greeting header, 4 stat tiles (2x2), line chart, shortcut grid
4. Billing — category tabs row, 3-col item grid, cart summary bar, bottom actions
5. Item List — searchable, swipe-to-reveal edit/delete
6. Reports — date filter tabs, summary cards, bar chart
